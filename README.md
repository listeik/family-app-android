# Family App для Android

Семейное Android-приложение для общих дел, покупок, еды в холодильнике, желаний, ленты активности и небольшого чата.

Связанный backend: [listeik/family-app-firebase](https://github.com/listeik/family-app-firebase).

## Технологии

- Kotlin
- Jetpack Compose и Material 3
- Firebase Authentication
- Cloud Firestore с обновлениями в реальном времени
- Firebase Cloud Messaging для push-уведомлений
- AES-256-GCM и Android Keystore для сквозного шифрования

## Возможности MVP

- анонимный вход Firebase для каждого устройства;
- создание семьи и защищенного приглашения `FH1...`;
- вход в существующую семью только по полному защищенному приглашению;
- семейные карточки категорий «Еда», «Покупки», «Дела» и «Хотелки»;
- дашборд Material 3 с виджетами, участниками семьи и пастельной цветовой системой;
- шкалы запасов еды, управление количеством `−1/+1` и точный остаток порций;
- история показывает, кто съел или вернул порцию и сколько осталось;
- чекбоксы для покупок, бытовых дел и желаний;
- общая лента событий;
- семейный чат;
- профиль с передачей ключа и выходом из семьи;
- сохранение FCM-токена для push-уведомлений.

## Сквозное шифрование

На устройстве создается случайный 256-битный семейный ключ. Название семьи, имена участников, названия карточек, сообщения и тексты событий шифруются до отправки в Firestore с помощью `AES/GCM/NoPadding`. Для каждого поля создается новый 96-битный nonce, а AAD связывает ciphertext с семьей, коллекцией, документом и полем.

Семейный ключ хранится в локальных preferences только в зашифрованном виде. Оборачивающий ключ находится в Android Keystore и не экспортируется. Сам семейный ключ передается другому устройству внутри приглашения `FH1.<код>.<ключ>` и никогда не сохраняется в Firebase.

Firestore по-прежнему видит служебные метаданные, необходимые приложению: идентификаторы, время, категорию, статус и количество порций. После выхода из семьи локальная копия ключа удаляется. Если приложение переустановлено, для восстановления доступа потребуется защищенное приглашение от другого участника.

При первом запуске версии `0.3.0` создатель старой семьи должен один раз нажать «Зашифровать семью», а остальные участники затем импортируют новое защищенное приглашение.

## Подключение Firebase

Рабочее приложение зарегистрировано в Firebase-проекте `family-app-listeik` с package name `com.listeik.familyapp`. Анонимный вход и Firestore уже настроены, правила опубликованы из репозитория backend.

Для локального запуска скачайте актуальный `google-services.json` из Firebase Console и поместите его в `app/google-services.json`.

Без `google-services.json` проект всё равно собирается, но вместо подключения к Firebase показывает экран настройки.

## Локальная сборка

Откройте проект в Android Studio и выполните синхронизацию Gradle либо запустите:

```powershell
.\gradlew.bat assembleDebug
```

Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Секреты и `google-services.json` намеренно не хранятся в Git.
